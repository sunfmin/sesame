# Budget per command

Generated by `tests/budget.rs`, which fails when this file differs from what its scenarios spend on the stand-in Core; `UPDATE_BUDGET=1 cargo test --test budget` rewrites it. Each method's cost is opcore's decision record 1, in the opcore source `Cargo.lock` pins. Each command is a new process: its first vault call after signing in spends one read more. The account's daily requests count each read and each write (opcore's decision record 7). A call 1Password refuses spends nothing. `scripts/e2e.sh` measures the same commands on the vault `sesame-scratch`.
